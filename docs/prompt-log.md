# Prompt Log（Agent 使用记录）

方案要求保留关键 Prompt，用于期末汇报与论文的过程材料。**每次用 Agent 完成一个完整功能就追加一条**，不要事后补写。

## 1. 记录规则

- 一条记录 = 一个完整功能（不要记录“帮我看看”这类探索性对话）。
- 必须写清：谁用的、哪个任务编号、Agent 实际改了什么、**人工改了哪里**。
- 涉及历史事实的 Prompt，必须注明“输出是否经过 B 回看原文”。
- 密钥、服务器地址、真实文献全文摘录不要写进本文件。

## 2. 七段式 Prompt 模板（[../AGENTS.md](../AGENTS.md) 第三节）

```
背景：项目是姓氏郡望与家族迁徙寻根系统，所有历史事实必须有可核验来源。
目标：只完成一个明确功能（例：实现 GET /api/surnames/{name} 总览接口）。
允许修改的文件：只列本任务目录内文件，不得修改其他模块。
输入和输出：输入数据从哪来、接口格式、异常情况返回什么。
验收标准：正常 / 空结果 / 异常 / 数据真实性四项分别写清楚。
禁止事项：不得编造来源，不得把 API Key 写入前端，不得删除已有数据。
运行方式：启动命令、测试命令、预期结果。
最终输出：修改文件清单、已完成内容、测试结果、遗留问题。
```
