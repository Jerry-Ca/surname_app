# 需求清单（课题 12 → 页面 / 接口 / 字段）

对应任务 **A-01**。本文件是范围裁决依据：**没写在这里的功能三天内不做**，想做请先改这份文件并说明砍掉什么。

## 1. 产品定位

“证据优先的姓氏研究工具”，不是只给结论的聊天机器人。用户可以看结论，也可以展开每条证据、查看出处、判断可信度，并知道哪些内容只是推测、哪些目前没有找到。

## 2. 四项硬性输出（课程要求）

| 硬性输出 | 用户看到什么 | 页面 | 接口 | 关键字段 |
| --- | --- | --- | --- | --- |
| 最早书证 | 年代、书名、卷次、原文、来源、核对状态 | 结果页「最早书证」区 + 来源详情页 | `GET /api/surnames/{name}/earliest` | `year_start`/`year_end`/`time_label`、`work_title`、`volume_or_section`、`original_excerpt`、`source_url`、`verification_status`、`sort_basis` |
| 历史郡望 | 郡望名称、时期、出处、原文、可信度 | 结果页「郡望」区 | `GET /api/surnames/{name}/commanderies` | `name`、`period`、`evidence`、`confidence`、`dispute_group` |
| 迁徙线索 | 时间、起点、终点、事件说明、证据、可信度 | 结果页「迁徙」区：时间线 + 关系图 | `GET /api/surnames/{name}/migrations` | `time_label`、`from_place`、`to_place`、`event_summary`、`evidences`、`confidence`、`location_status` |
| 语料审计 | 查过哪些语料、查询词、结果数、查不到的原因 | 结果页「语料审计」区 + 未收录页 | `GET /api/surnames/{name}/corpus-checks` | `corpus_name`、`query_text`、`checked_at`、`result_count`、`no_result_reason`、`operator` |

补充入口：`GET /api/surnames/{name}` 总览（首屏一次拿齐摘要）、`POST /api/ask` 证据问答、`GET /api/health` 健康检查、`POST /api/admin/import`、`POST /api/admin/reindex`。

| 维度 | 挑战层目标 | 本项目实现方式 | 验收证据 |
| --- | --- | --- | --- |

## 4. 用户端功能与必须处理的情况

| 功能区 | 用户看到的内容 | 必须处理的情况 |
| --- | --- | --- |
| 姓氏输入 | 单姓、复姓、别名、繁体或异体输入 | 空输入、非汉字、过长文本、未收录姓氏 |
| 最早书证 | 年代、书名、卷次、原文、来源、核对状态 | 只能确认“当前语料中最早”时必须明确表述 |
| 历史郡望 | 郡望名称、时期、出处、原文、可信度 | 多个说法并列展示，不强行合并 |
| 迁徙时间线 | 时间、起点、终点、事件说明、证据 | 时间不精确、地名无法定位、关系存在争议 |
| 迁徙关系图 | 节点、箭头、证据编号、定位状态 | 不使用现代人口分布反推古代迁徙 |
| 语料审计 | 查过的语料、查询词、结果数、查不到原因 | 平台没有全文检索或来源暂时不可访问 |
| 证据问答 | 基于证据的摘要、证据编号、引用来源 | 模型失败、证据不足、问题超出资料范围 |

## 5. 核心交互流程

1. 用户输入姓氏并点击查询。
2. 前端调用后端 API，后端先做姓氏标准化和别名匹配。
3. 后端查询已核对证据，再用全文检索和向量检索补充相关证据。
4. 前端展示最早书证、郡望、迁徙和语料审计。
5. 用户提问时，后端把检索到的证据片段和来源编号交给大模型。
6. 大模型生成解释，后端检查回答是否带证据编号。
7. 没有证据时显示“当前资料不足以确认”，不生成确定性结论。

## 6. 必须实现的异常状态（六种，缺一不可）

| 情况 | 必须的页面表现 |
| --- | --- |
| 姓氏未收录 | 显示已查询范围与语料审计，不显示空白页 |
| 没有迁徙记录 | 显示“当前资料中未找到可核对的迁徙线索” |
| 来源链接失效 | 保留书名、卷次、原文与访问时间，标记“链接待复查” |
| 大模型不可用 | 结构化证据仍可查询，智能摘要区显示“暂不可用” |
| 存在争议 | 并列展示不同说法、来源与核对状态，不自动二选一 |
| 地点无法定位 | 显示“无法定位”或“大致范围”，不伪造精确坐标 |

## 7. 数据范围（三天）

- 原子证据 ≥100 条，覆盖 **20—30 个**资料相对丰富的姓氏，而不是给 100 个姓氏各做一条。
- 优先姓氏：李、王、张、刘、陈、杨、赵、黄、周、吴、徐、孙、胡、朱、高、林、何、郭、马、罗、梁、宋、郑、谢、韩、唐、冯、于、董、程。
- 每个姓氏包含最早书证、郡望、迁徙、语料审计四类中的至少两类记录。
